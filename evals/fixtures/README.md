# 冻结评测数据

本目录保存 RecruitOps Agent 的离线、匿名、无密钥评测输入。评测不得访问招聘
网站、邮箱、浏览器登录态、模型服务或正式数据库，也不得修改主秋招系统文件。

## 五个 MVP 场景

| 场景 | 固定断言 |
| --- | --- |
| 今日安排 | 只返回指定日期的日程并保留投递关联和来源。 |
| 今日新增 | 只返回首次出现于指定日期、确认 2027 届、正式批或提前批岗位。 |
| 推荐解释 | 返回完整 JD 和已存分析，并附带结构化个人画像的明确证据。 |
| 投递查询 | 歧义查询安全停止，不猜测投递记录，也不修改阶段。 |
| 招聘邮件详情 | 返回持久化的脱敏邮件，不修改邮件或投递状态。 |

`mvp_snapshot.json` 提供岗位、分析、投递和日程；邮件和个人画像由运行器创建匿名
内存 fixture。`mvp_cases.json` 保存协议级场景说明和一个禁止源删除的边界用例。

## Crawler RAG

`rag_cases.json` 只包含 Crawler/ATS 接入和届别证据，不包含简历或个人画像。三条
可回答用例验证引用召回，一条“验证码绕过”用例必须拒答。

`rag_onboarding_cases.json` 与 `website_blind_30.json` 是合成接入评测和盲测输入，
只能作为回归信号，不能表述为真实网站成功率。

## 运行

```powershell
python -m evals.mvp_runner
python -m evals.rag_runner
python -m evals.rag_ab
```

离线结果不能替代真实网站、真实 Edge 或真实邮箱验收。
