# Job Intelligence

1. Use SQL-backed MCP tools for job lists and details.
2. Apply cohort and internship rules before matching: only confirmed 2027 full-time campus jobs are
   recommendation candidates.
3. Distinguish missing data from zero results. Mention stale crawl or incomplete JD evidence when
   relevant.
4. Ground comparisons in job title, complete JD, location, batch, score evidence, and job URL.
5. Never manufacture a score or treat conversation memory as the current database.
