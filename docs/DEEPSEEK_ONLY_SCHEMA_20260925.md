# DeepSeek 专用接口与截断验证

日期：2026-09-25。此文描述当前源码；不代表已替换桌面正式版或云端压缩包。

## 变更范围

- 模型服务只允许 DeepSeek 官方 HTTPS 地址，模型为 deepseek-flash / deepseek-v4-pro。配置页删除第三方兼容服务，地址锁定，模型使用下拉选择。API、共享客户端、桌面能力门禁和助理配置同步校验。
- 保留 DeepSeek 官方 Responses、Anthropic Messages 和视觉 Chat 接口的协议适配，不是保留第三方 OpenAI 服务。Codex 的 wire_api=responses、requires_openai_auth=false 是其必要配置。
- 旧的第三方地址/模型在读取时停用，密钥不转发、不自动迁移；原配置文件不会因读取被改写。用户保存新的官方连接后恢复功能。旧官方 /v1 + openai 协议标记可安全归一化。
- 远程兼容向量接口停用，本地检索不发送数据。历史 semantic_document_chunks 保留，不混用新向量写入；如需这些文档参与本地检索，应明确选择原文件重新导入本地索引。独立开发用 embedding 服务未删除，不再被产品连接。

## 简历、评分与邮件结构化输出

- 使用 DeepSeek 官方 /responses 的 text.format=json_schema，把完整 Schema 发送给服务端，不再只靠提示词 + json_object。
- 统一 result 信封支持对象和数组；保留根级 $defs 引用，声明字段 required，关闭额外属性，移除默认值。不会修改调用者传入的 Schema。
- 仅接受 completed 响应；incomplete、拒答、空输出、坏 JSON、错误信封均不得当成成功。普通文本返回也不接受 max_tokens 截断。
- 简历、邮件结构化请求关闭思考，避免思考消耗全部输出额度；评分保留用户配置的思考设置。
- 简历两次有界尝试，输出额度 4000 → 8000；字段不合格时下一次携带字段路径和错误类型。没有学历可为 null，没有技能或项目用 []，禁止编造。失败不覆盖已有资料。
- 评分最多三次尝试，输出预算逐次提高、上限 8000；四个核心分项及证据仍执行本地类型、范围和矛盾检查。缺字段不默认为 0；真正缺乏匹配证据的合理 0 分仍允许。失败不以假分数覆盖旧有效评分。
- 前端解析时限覆盖后端两次尝试；非 JSON 的 HTTP 错误显示可理解的状态提示，不再只显示 Unexpected token。保存响应丢失时要求重新读取确认，不虚称未保存。

官方依据：[DeepSeek Responses API](https://api-docs.deepseek.com/api/create-response/)。
Schema 约束保证的是结构要求，不保证事实判断正确，也不能消除超时、限流、额度不足、拒答或输出截断。

## 全量爬取中断的结论

- 默认六小时仍是单段执行预算，不是正常全量任务的总寿命。到达预算时协作停止、提交批次和检查点，然后在同一任务编号与锁下续段。
- 自动续段必须有可验证的冻结范围/断点和实际进展；用户暂停/取消、断点不可用、连续无进展不会无限重启。
- 来源单条坏数据隔离，可用部分来源继续；不完整来源不能触发旧岗位下架。岗位列表、详情、评分分批持久化，失败不撤销之前提交的成果。
- 程序关闭后不能继续运行，重新打开后需按断点续跑。单公司超时、网站限制、网络/磁盘/数据库故障仍可能出现；不能宣称“再也不会中断”。检查点落盘失败时宁可安全暂停，也不声称已经保存成功。

## 验证方法与交付边界

均使用合成资料、模拟网络和临时数据库，没有读取真实简历/邮件或消耗用户模型额度。

- Schema 请求、坏字段纠正、拒答/截断/空输出、旧密钥迁移、配置门禁、实际评分链路与桌面能力回归。
- 加速时限模拟测试覆盖多段续跑、同一锁/编号、冻结范围、不重复发现、评分续段、显式暂停/取消、无进展与损坏断点。
- 来源局部错误、先提交后断点失败、损坏备份恢复、部分失败保留旧结果、10/10/6 并发与跨进程资源上限。
- UI 合成浏览器测试与错误响应/时限单元测试；迁移静态检查。

未进行真实网站六小时连续运行或 DeepSeek 官方在线验收；也未新增 PDF OCR/截图解析功能。本轮不部署、不打包、不上传，既有候选包不包含本轮新改动。
