## 主要更新

### 1. 启动与安装包完整性

- 修复管理员启动场景下 PostgreSQL 子进程权限处理：使用受限令牌，实例访问权限对应实际 Windows 用户，兼容旧实例权限修复。
- 保留已有异常退出恢复和首次空库初始化失败重试机制；不自动删除已有业务数据库来“修复”启动。
- 继承 v0.1.4 的爬虫子进程入口补全与强制打包校验，避免遗漏 `scripts.run_agent_crawler` 等入口。发布包不包含用户 `.data`。

### 2. 简历解析与岗位评分

- OpenAI-compatible 结构化请求提供完整字段约定；可识别的 DeepSeek 请求明确发送关闭思考参数，避免开关在请求转换时丢失。第三方网关仍需支持相应参数。
- 简历解析保留结构校验和有限纠错重试，失败不覆盖已有有效档案。
- 评分严格校验四个维度：核心方向 30 分、必备技能 30 分、项目证据 25 分、工程能力 15 分。缺少维度不再默认补 0 后当成有效低分入库。
- 无效评分会进入失败/待重试处理，保留已有有效评分；真实不匹配仍可能得 0 分。旧版已经产生的异常评分不会因升级自动重算，需要另行执行评分重算。

### 3. 全量任务、断点与进度

- 全量任务到达每段 6 小时预算后，安全保存并验证断点，以同一任务编号继续剩余工作；评分阶段只处理仍待评分的岗位，不将接续变成新一轮全量扫描。
- 暂停、取消优先；冻结范围或断点无效、业务失败、连续接续没有进展时停止。用户指定的批量范围不会被自动扩大。
- 助理可以查询中断任务、暂停、取消和续跑，不再要求用户复制内部运行编号；旧版无控制回执的中断记录也可取消。取消保留已经入库的结果。
- 任务进度卡覆盖抓取、投递复核和邮件处理，默认只显示当前活跃任务。公司抓取按“已处理 / 总数”展示，处理过不等于全部抓取成功。
- 全量爬取采用后台运行；投递复核与邮件处理在当前助理回合等待并返回结果，不要求用户再问一次才获取结果。

### 4. 投递记录与官网复核

- 修复自动选取全部未挂记录时，0 条或超过 50 条记录导致复核任务启动失败的问题；真实业务数量不再误用任务步骤上限。
- 分批连续复核并保留检查点，正常批次间隙不再误报暂停；明确区分已处理、待重试和无法确认，不把旧结果当成本轮结果。
- 投递记录支持按公司或岗位名称搜索，并支持修改公司名称、岗位名称。
- 移除重复的阶段下拉筛选，各阶段看板独立加载与“加载更多”，避免全局前 50 条属于同一阶段时，其他阶段错误显示为空。

### 5. 招聘邮件、配置与桌面体验

- 邮件无法可靠关联投递时，可提出候选并请求用户确认；用户明确批准后才绑定、更正或解除关联。允许无需具体岗位的通知保留为未关联记录。
- 不再将历史默认 0 值显示为有意义的置信度百分比；邮件处理与投递阶段变更仍需满足证据和权限规则。
- 优化岗位数据分页与重复读取，保留搜索状态和加载失败时的现有记录；不承诺所有机器和查询均无延迟。
- 配置提示更加就近，保存后的受支持配置直接应用；邮箱未配置不阻断岗位抓取、评分与其他非邮箱功能。
- 包含内置招聘浏览器的表单扫描、填写/撤销、投递保存与上下文适配优化；不代表与原 Edge 插件或所有招聘网站完全等效。

## 旧版本已经爬取到数据，如何升级？

**已有数据用户请以本节和[完整升级步骤](https://github.com/849879772/recruitops-agent/blob/main/docs/UPGRADE_EXISTING_DATA.md)为准；不要将整个 `.data` 直接搬到不同绝对路径后启动。** 随包 README 中“先解压到新目录”只是准备步骤，最终仍需恢复为旧程序的原安装路径。

1. 等任务结束，从软件和系统托盘正常退出；不要强制结束数据库进程。
2. 完整备份旧程序旁的 `.data`，保留旧程序与升级前独立备份。
3. 把新 ZIP 解压到同盘临时目录，先不要启动。
4. 将旧程序目录改名保留，再把新程序目录改为旧版原来的**相同绝对路径**。
5. 把旧版完整 `.data` 放回该路径，使用同一台电脑、同一 Windows 用户正常启动。
6. 核对岗位、评分、投递记录、已同步邮件、配置与日程。失败时保留日志和原始数据，不要删除数据库重建。

不要只复制 `pgdata`、单独修改 `instance.json`，也不要将旧 `resources` 混入新版资源。换电脑、换账户、换路径不能直接按此方法迁移。`.data` 含个人资料和凭据，不能上传到公共网盘或仓库。

## 验证范围与仍需注意的限制

- 已完成结构化请求、评分校验、任务接续/取消、投递与邮件批处理、分页、前端和打包等离线回归，以及真实打包 EXE 的隔离数据库启动、配置保存、匿名填表、合成投递写入与重启持久化验证。
- ZIP CRC 与 6305 个文件的逐项哈希校验通过，已核对爬虫入口和最新修复源码。
- 6 小时边界使用短预算模拟测试，不等同于所有用户环境的真实连续六小时联网验收。软件或电脑关闭后不会继续工作。
- 网络、来源站点不可用、登录/验证码、模型或代理服务不兼容、Windows 安全策略等仍可能造成失败。本版不保证所有机器不再出现 `initdb_failed`，也不保证模型永远不缺字段。
- 本包为未进行代码签名的 Windows 便携版，不是安装器；请完整解压到短且可写的路径，例如 `D:\RecruitOps`。
