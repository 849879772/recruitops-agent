## 旧版已有岗位数据的用户

如果 v0.1.1 或 v0.1.2 已经成功爬取岗位，或者已有投递记录、已同步邮件，不要直接在新目录启动空白实例，也不要只搬 `pgdata`。先正常结束后台任务并退出旧版，完整备份原目录的 `.data`，把新版解压到临时目录，然后让新版程序回到旧版的**相同绝对路径**，将整个 `.data` 原样放回。必须使用原 Windows 账户启动。详细的备份、移动、验证及回退条件见 [已有数据的桌面版升级步骤](UPGRADE_EXISTING_DATA.md)。

`.data` 含数据库、配置、凭据与私人记录，发布包不含任何用户 `.data`；不要把自己的 `.data` 上传到公开仓库或分享链接。
